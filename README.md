# Instalação

1. Baixe o arquivo compactado ou clone o repositório com git clone https://github.com/victorsmyk/portao-backend.git .
2. Execute o arquivo .bat ou .sh de acordo com o seu sistema operacional
3. Conecte o Arduino ao seu PC por meio de uma porta USB
4. Mantenha o aplicativo aberto para a detecção e escrita dos logs
5. Verifique os logs clicando em index.html
6. A página deve ser recarregada para que um novo log seja renderizado
